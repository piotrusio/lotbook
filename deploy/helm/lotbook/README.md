# lotbook

The Helm chart of [Lotbook](https://github.com/piotrusio/lotbook), a lot
genealogy engine. It installs Lotbook alone: PostgreSQL, Kafka and the
journal's topic come from the environment.

What the environment must provide, and how to install and upgrade, is in
[installation.md](https://github.com/piotrusio/lotbook/blob/main/.docs/system/installation.md).
Every value is documented in [`values.yaml`](values.yaml).
