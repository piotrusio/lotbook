# Contributing

Thanks for your interest in lotbook!

This project is **open source but not open contribution**. The code is published
under the Apache 2.0 license, but development is done only by the maintainers.

## What we accept

- **Issues**: bug reports, feature requests and questions are welcome.
  Please use one of the [issue templates](https://github.com/piotrusio/lotbook/issues/new/choose).

## What we don't accept

- **Pull requests from outside contributors.** PR creation is limited to
  repository collaborators. If you've found a bug or have an idea, please open
  an issue describing it instead.

You're free to fork the project under the terms of the [license](LICENSE).

## Security

Please don't report security vulnerabilities in public issues. Use
[GitHub private vulnerability reporting](https://github.com/piotrusio/lotbook/security/advisories/new) instead.
